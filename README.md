# abstinensa.no

Personlig nettside for Stine Egeli Øvrebø — strategisk rådgiver innen AI-strategi, implementering og digital transformasjon.

Publisert på [abstinensa.no](https://abstinensa.no/) via GitHub Pages.

## Struktur

- `index.html` — forside (norsk)
- `en.html` — forside (engelsk)
- `modenhet/` — AI-modenhetsvurdering
- `oslo-events.html` — Oslo Nå
- `ai-daily/` — daglige AI-oppdateringer
- `sondreogjohanne/` — separat miniapp
- `spill.html`, `pokemon.html` — eksperimenter
